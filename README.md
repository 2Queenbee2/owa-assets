# owa-assets

Public assets for the OtherWorlds Awakening: Frontier client mod.

- `logo.png` is the title-screen logo. Replace it (same filename) to change the logo for everyone on their next launch.
  Direct link: https://raw.githubusercontent.com/2Queenbee2/owa-assets/main/logo.png
  Recommended size about 1200x434, transparent PNG, under 1 MB.
